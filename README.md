## 🚀 Getting Started

### Prerequisites
- Java JDK 8 or higher
- Python 3.x
- C++ compiler (g++/clang)

### Compilation & Execution

**Java:**
```bash
# Compile
javac ProblemName.java

# Run
java ProblemName < input.txt
```

**Python:**
```bash
python3 problem_name.py < input.txt
```

**C++:**
```bash
# Compile
g++ -o program problem_name.cpp

# Run
./program < input.txt
```
